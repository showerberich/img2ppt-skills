# img2ppt skills

Agent skills for converting images and PDFs into fully editable PowerPoint files.

## Skills

| Skill | Description |
|---|---|
| [img2ppt](skills/img2ppt/SKILL.md) | Convert an image or PDF into an editable PPTX through the img2ppt API. Every text box, shape, and icon is a native PowerPoint object. |

## Install

```bash
npx skills add <owner>/img2ppt-skills --skill img2ppt
```

The skill needs `IMG2PPT_TOKEN`. See [skills/img2ppt/README.md](skills/img2ppt/README.md) for setup, pricing, and usage.
